You receive an exercise file and one bug report. 
Your task is to write one test function that proves the bug described in the report. 

A good test fails on the current buggy code and passes once the bug is fixed.

Strict Rules:
1. Output ONLY Python code. Do not include any markdown formatting, explanations, or introductory/concluding text.
2. Write exactly one function whose name starts with `test_`.
3. Use a standard `assert` statement to check the expected return value. DO NOT test `__doc__` or docstrings.
4. Do not include any `import` statements (the functions from the exercise file are already imported for you).
